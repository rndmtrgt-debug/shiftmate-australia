SHIFTMATE AUSTRALIA — VERSION 3

WHAT'S NEW
- New browser-based Shift Tracker with local storage.
- CSV export for shift records.
- New “How to check your pay” guide.
- Expanded homepage, trust messaging and monetisation-ready placements.
- Custom 404 page and security headers for compatible static hosts.
- Updated sitemap and robots files.
- No external JavaScript libraries, analytics, ads or tracking included.

IMPORTANT BEFORE LAUNCH
1. Choose your final domain.
2. Production URL is set to https://shiftmateaustraliav4-1.vercel.app in sitemap.xml, robots.txt, canonical tags and Open Graph URL metadata.
3. Add canonical and og:url tags after the domain is known.
4. Test every calculator and link after upload.
5. Do not advertise ShiftMate estimates as official award calculations.
6. Keep links/content about pay rules current. Fair Work Ombudsman should remain the authoritative source.

FREE HOSTING
This package is static HTML/CSS/JavaScript and can be deployed to a static host. Cloudflare Pages supports static HTML and provides a pages.dev subdomain. No build process is required for this package.

MONETISATION
The package contains reserved placements only. No advertising, affiliate links or paid offers are active. Add these only after traffic exists and ensure disclosures are clear.
