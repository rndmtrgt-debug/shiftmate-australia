Feedback and corrections

You can currently report public website feedback and technical issues through the TORVILO GitHub repository.

Open GitHub issues

Protect your privacy: GitHub issues are public. Do not post payslips, tax information, addresses, phone numbers, account details, identity documents or other sensitive personal information.

What to include

For a website problem, include the page name, what you expected to happen and what happened instead. For a factual correction, include the page and, where possible, a link to an authoritative source supporting the correction.
